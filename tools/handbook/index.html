About this guide

Load your game

In the game, open START › GUIDE SYNC (saving also syncs). The game writes guide-sync.bin into its data folder:

  • Linux ~/.local/share/pokemon-love2d/
  • Windows %APPDATA%\pokemon-love2d\
  • macOS ~/Library/Application Support/pokemon-love2d/

Then mod_storage › emerald › your playthrough › g3_campaign › guide-sync.bin. The game names the first characters of the playthrough folder when you sync.

Chrome and Edge remember the file: after the first pick, Reload reads it again in one click. Firefox and Safari ask for the file each time. In co-op your partner’s party and box come along once you have played together.
